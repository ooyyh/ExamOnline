# 用户手册

## 1. 启动
1. 启动后端 `mvn spring-boot:run`
2. 启动前端 `npm run dev`
3. 浏览器访问前端地址

## 2. 管理员操作
- 登录后进入管理员端
- 维护用户和班级
- 查看日志与统计

## 3. 教师操作
- 进入题库页面新增题目
- 下载模板后批量导入
- 通过题目 ID 组卷或自动组卷
- 发布试卷并查看分析、导出成绩

## 4. 学生操作
- 登录后查看待考列表
- 点击开始考试进入答题界面
- 系统自动保存答案
- 切屏超过限制时自动交卷
- 查看历史考试、错题本和成绩趋势

## 5. 常见问题
- **无法登录**：确认账号密码是否正确
- **看不到考试**：确认试卷已发布且时间窗口有效
