# 系统设计文档

## 1. 总体架构
- **前端**：Vue 3 + Vite，负责页面展示与交互
- **后端**：Spring Boot + Spring Web + Spring Data JPA
- **数据库**：H2 默认可运行，提供 MySQL 兼容脚本

## 2. 数据库设计
核心表：
- `app_users`
- `school_classes`
- `questions`
- `exam_papers`
- `paper_questions`
- `exam_attempts`
- `attempt_answers`
- `operation_logs`

## 3. 接口设计
- `POST /api/auth/login`
- `GET /api/admin/stats`
- `GET/POST/DELETE /api/admin/users`
- `GET/POST/DELETE /api/admin/classes`
- `GET/POST/DELETE /api/teacher/questions`
- `POST /api/teacher/questions/import`
- `GET /api/teacher/questions/template`
- `GET/POST /api/teacher/papers`
- `POST /api/teacher/papers/{id}/publish`
- `GET /api/student/exams`
- `POST /api/student/exams/{paperId}/start`
- `POST /api/student/attempts/{attemptId}/answer`
- `POST /api/student/attempts/{attemptId}/submit`

## 4. 关键模块
- 权限控制：按角色展示功能区
- 防作弊：切屏计数超限自动交卷
- 自动组卷：按题型/科目/难度抽题
- 自动阅卷：客观题按标准答案判分
