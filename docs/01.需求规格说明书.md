# 需求规格说明书

## 1. 项目背景与目标
在线考试系统用于支持学校日常测验、阶段考试与成绩分析，覆盖管理员、教师、学生三类角色，完成题库建设、组卷、发布、考试、阅卷、统计和错题复习闭环。

## 2. 用户角色
- **管理员**：学生/教师/班级基础数据维护，查看系统日志与统计。
- **教师**：题库管理、手动/自动组卷、发布考试、成绩分析、导出成绩。
- **学生**：查看待考、参加考试、历史回看、错题本、个人成绩分析、修改密码。

## 3. 功能需求
### 3.1 管理员端
- 学生管理：增删改查
- 教师管理：增删改查
- 班级/院系管理：增删改查
- 系统日志：查看关键操作记录
- 数据统计：用户数、考试场次、参与人次等

### 3.2 教师端
- 题库管理：单选、多选、判断、填空、简答、编程题
- 批量导入：Excel 题目导入、模板下载
- 试卷管理：手动组卷、自动组卷、试卷预览
- 考试管理：发布、监控、导出成绩
- 阅卷与分析：自动阅卷、成绩统计、错题分析

### 3.3 学生端
- 待考列表：按时间展示可参加考试
- 在线考试：倒计时、自动保存、防切屏监测
- 考试记录：历史成绩和答卷详情
- 错题本：自动收录错题
- 成绩单：个人成绩趋势与知识点分析
- 个人信息：密码修改

## 4. 非功能需求
- 性能：支持基本并发考试与查询
- 安全：密码保护、考试防切屏提醒
- 易用性：角色清晰、操作路径短

## 5. 界面原型说明
- 登录页
- 管理员首页
- 教师题库/组卷页
- 学生考试与错题本页面
